YT DLP GUI

EscritorioFecha: agosto de 2024

Interfaz gráfica de escritorio en Python (CustomTkinter) para yt-dlp: descarga videos de cualquier sitio compatible y convierte calidad y formato.

Sobre el proyecto

Una aplicación de escritorio para descargar videos de cualquier sitio que admita yt_dlp.

La aplicación se construye alrededor del paquete yt_dlp, para darle una interfaz gráfica.

Además de descargar videos de cualquier sitio compatible y en alta calidad, también permite convertir calidad y formato.

Para la interfaz gráfica se usó el paquete CustomTkinter.
