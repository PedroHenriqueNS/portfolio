Cloud Barueri

Armazenamento de arquivos grandes em servidor local com interface no estilo Google Drive: React.js, API em Node.js e MySQL, rodando em Docker.

Tecnologias: React.js, Node.js, Express, Docker, MySQL

Sobre o projeto

Uma aplicação web para armazenar arquivos grandes em um servidor local específico.

A ideia é lidar com os arquivos de gravação e transmissão com facilidade, armazenando e acessando com uma interface familiar a quem usa o Google Drive.

A página web é construída com React.js.

O back-end é feito em Node.js, com banco de dados MySQL e uma unidade de armazenamento fornecida pelo Docker no sistema operacional Unraid.

Código e acesso privados, por contrato com o cliente.
