SodiEasy

App mobile para orçamentos de materiais de construção da Sodimac pelo ID do produto, com API em Node.js que faz web scraping dos preços.

Tecnologias: React Native, Expo, Node.js, Express

Sobre o projeto

Um aplicativo mobile para fazer orçamentos de materiais de construção com produtos disponíveis na Sodimac.

A aplicação faz requisições a uma API que realiza o web scraping do site da Sodimac a partir do ID do produto, salvando os dados e atualizando-os conforme mudam no site oficial.

O projeto é destinado a um atendente da empresa, que naturalmente busca os produtos pelo ID; por isso toda a busca é baseada no ID do produto.

O aplicativo é construído em React Native com o framework Expo.

Código e acesso privados, por contrato com o cliente.
