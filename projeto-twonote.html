TwoNote

Primeiro projeto mobile, da faculdade: bloco de notas com salvamento automático feito em Angular com o framework Ionic.

Tecnologias: Ionic, Angular

Sobre o projeto

O primeiro projeto mobile, feito para finalizar o semestre na universidade.

O objetivo é um bloco de notas com salvamento automático; daí o nome, inspirado no "Microsoft OneNote" 😁😁

A aplicação é construída com Angular através do framework Ionic.
