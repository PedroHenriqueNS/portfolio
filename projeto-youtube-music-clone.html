Youtube Music Clone

Clone mobile do antigo YouTube Music que toca as músicas salvas no aparelho, feito em React Native com Expo.

Tecnologias: React Native, Expo

Sobre o projeto

Um aplicativo mobile clone do antigo YouTube Music, com acesso às músicas salvas localmente no dispositivo.

Uma interface simples, muito parecida com a original, mas sem a pesquisa de músicas online no YouTube.

A aplicação é feita em React Native com o framework Expo.
