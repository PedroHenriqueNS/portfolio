YT DLP GUI

Interface gráfica desktop em Python (CustomTkinter) para o yt-dlp: baixa vídeos de qualquer site suportado e converte qualidade e formato.

Agosto de 2024

Tecnologias: Python

Sobre o projeto

Um aplicativo desktop para baixar vídeos de qualquer site que o yt_dlp suporte.

A aplicação é construída em torno do pacote yt_dlp, com o objetivo de dar a ele uma interface gráfica.

Além de baixar vídeos de qualquer site suportado e em alta qualidade, também é possível converter qualidade e formato.

Para a interface gráfica foi usado o pacote CustomTkinter.
