---
summary: "Large file storage on a local server with a Google Drive-style interface: React.js, a Node.js API and MySQL, running on Docker."
---

A web application to store large files on a specific local server.

The idea is to handle recording and broadcast files easily, storing and accessing them through an interface familiar to anyone who uses **Google Drive**.

The web page is built with **React.js**.

The back end is written in **Node.js**, with a **MySQL** database and a storage unit provided by **Docker** on the **Unraid** operating system.
