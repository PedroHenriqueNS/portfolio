---
summary: "Large-file storage on a local server with a Google Drive-style interface: React.js, a Node.js API and MySQL, running on Docker."
---

A web app for storing large files on a specific local server.

The goal is to make recording and broadcast files easy to handle: you store and open them through an interface that feels familiar to anyone who uses **Google Drive**.

The front end is built with **React.js**.

The back end runs on **Node.js**, with a **MySQL** database and storage provided by **Docker** on the **Unraid** operating system.
