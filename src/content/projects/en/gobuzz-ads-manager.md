---
summary: "Meta ads manager in Next.js: publishing, automatic scheduling and insights, with all logic on the server and data in Appwrite."
---

A **Meta** ads manager where you can publish new ads, schedule automatic ads and view insights about them.

The application makes requests directly to the **Meta** API using previously registered data about the profiles and ad accounts, which are stored in the **Appwrite** database.

Every action runs on the server with **Next.js** server-side rendering: the user only gets the information that should appear in the interface.
