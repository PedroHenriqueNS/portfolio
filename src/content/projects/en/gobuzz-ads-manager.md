---
summary: "Meta ads manager in Next.js: publishing, automatic scheduling and insights, with all the logic on the server and the data in Appwrite."
---

A **Meta** ads manager for publishing new ads, scheduling automatic ones and viewing insights about them.

The app calls the **Meta** API directly, using previously registered data about the profiles and ad accounts, stored in the **Appwrite** database.

Every action runs on the server with **Next.js** server-side rendering, so users only get the information the interface needs to show.
