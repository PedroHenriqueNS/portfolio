---

Una aplicación de escritorio para recortar PDFs automáticamente.

Se construyó para recortar informes de **Power BI**, que dejan grandes márgenes cuando se exportan a PDF.

La aplicación se arma con **Electron** y **React.js** con **Vite**.

Para recortar, el usuario selecciona varios archivos, elige la configuración y los envía a una API local que abre la aplicación, hecha con **Flask** y **Python**.
