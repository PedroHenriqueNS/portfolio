summary: "Almacenamiento de archivos grandes en servidor local con interfaz al estilo Google Drive: React.js, API en Node.js y MySQL, ejecutándose en Docker."
---

Una aplicación web para almacenar archivos grandes en un servidor local específico.

La idea es manejar con facilidad los archivos de grabación y transmisión, almacenándolos y accediendo a ellos con una interfaz familiar para quien usa **Google Drive**.

La página web se construye con **React.js**.

El back-end está hecho en **Node.js**, con base de datos **MySQL** y una unidad de almacenamiento provista por **Docker** en el sistema operativo **Unraid**.
