---

Una aplicación web para almacenar archivos grandes en un servidor local específico.

La idea es manejar con facilidad los archivos de grabación y transmisión, guardándolos y abriéndolos desde una interfaz familiar para quien usa **Google Drive**.

La página web está hecha con **React.js**.

El back-end está escrito en **Node.js**, con base de datos **MySQL** y una unidad de almacenamiento provista por **Docker** en el sistema operativo **Unraid**.
