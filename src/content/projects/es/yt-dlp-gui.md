summary: "Interfaz gráfica de escritorio en Python (CustomTkinter) para yt-dlp: descarga videos de cualquier sitio compatible y convierte calidad y formato."
---

Una aplicación de escritorio para descargar videos de cualquier sitio que **yt_dlp** soporte.

La aplicación se construye alrededor del paquete **yt_dlp**, con el objetivo de darle una interfaz gráfica.

Además de descargar videos en alta calidad de cualquier sitio compatible, también es posible convertir calidad y formato.

Para la interfaz gráfica se usó el paquete **CustomTkinter**.
