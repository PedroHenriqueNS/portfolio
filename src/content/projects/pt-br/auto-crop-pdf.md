summary: "App desktop que recorta PDFs automaticamente, feito para relatórios do Power BI: Electron e React no front, API local em Flask (Python) no back."
---

Uma aplicação desktop para recortar PDFs automaticamente.

Foi construída para recortar relatórios do **Power BI**, que deixam grandes bordas quando exportados em PDF.

A aplicação é montada com **Electron** e **React.js** com **Vite**.

Para recortar, o usuário seleciona vários arquivos, escolhe as configurações e os envia para uma API local aberta pelo aplicativo, feita em **Flask** com **Python**.
